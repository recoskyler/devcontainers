  <name>Task 1: Create Dockerfile with system-level installs</name>
  <files>trixie-vnc-flutter-rust-nvm-uv-claude/Dockerfile</files>
  <action>
Create the directory `trixie-vnc-flutter-rust-nvm-uv-claude/` and a new `Dockerfile` inside it.

**Structure the Dockerfile as follows:**

1. **FROM directive** (CONV-01):
   ```
   FROM trixie-vnc-nvm-uv-claude:latest
   ```

2. **USER root block** with `ENV HOME=/root` (project convention):

3. **Environment variables** (set early so they are available in subsequent RUN commands):
   ```
   ENV JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
   ENV ANDROID_HOME=/home/dev/android-sdk
   ENV ANDROID_SDK_ROOT=$ANDROID_HOME
   ENV CHROME_EXECUTABLE=/usr/bin/chromium
   ENV PATH=$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH
   ```

4. **apt-get install block** -- single RUN with all system packages, cleaned in same layer:
   - `openjdk-21-jdk-headless` (SDK-01)
   - `chromium` (WEB-01)
   - Emulator/Studio GUI dependencies (DISP-01): `libgl1`, `libpulse0`, `libx11-6`, `libxcb1`, `libxcomposite1`, `libxcursor1`, `libxi6`, `libxext6`, `libxfixes3`, `libxdamage1`, `libnss3`, `libglu1-mesa`, `libxrandr2`, `libxtst6`, `libdbus-1-3`, `libfontconfig1`, `libasound2t64`, `libstdc++6`, `zlib1g`
   - `unzip` (for cmdline-tools ZIP extraction)
   - End with `apt-get autoremove -y && apt-get clean && rm -rf /var/lib/apt/lists/*`

5. **Android cmdline-tools bootstrap** -- single RUN, download + extract + cleanup in same layer:
   ```
   ARG CMDLINE_TOOLS_URL=https://dl.google.com/android/repository/commandlinetools-linux-14742923_latest.zip
   RUN mkdir -p /home/dev/android-sdk/cmdline-tools \
       && curl -fsSL "$CMDLINE_TOOLS_URL" -o /tmp/cmdline-tools.zip \
       && unzip -q /tmp/cmdline-tools.zip -d /tmp \
       && mv /tmp/cmdline-tools /home/dev/android-sdk/cmdline-tools/latest \
       && rm /tmp/cmdline-tools.zip
   ```
   CRITICAL: The extracted directory must be at `$ANDROID_HOME/cmdline-tools/latest/` (not nested). See Pitfall 1 in research.

6. **Android Studio tarball** (IDE-01) -- single RUN, download + extract + cleanup:
   ```
   # Android Studio Panda 1 | 2025.3.1.8
   ARG ANDROID_STUDIO_URL=https://redirector.gvt1.com/edgedl/android/studio/ide-zips/2025.3.1.8/android-studio-2025.3.1.8-linux.tar.gz
   RUN curl -fsSL "$ANDROID_STUDIO_URL" -o /tmp/android-studio.tar.gz \
       && tar -xzf /tmp/android-studio.tar.gz -C /opt/ \
       && rm /tmp/android-studio.tar.gz
   ```
   The tarball extracts to `android-studio/` by default, so `/opt/android-studio/bin/studio.sh` must exist after extraction. Verify the tarball contents structure. Use the redirector URL which is more stable than edge CDN URLs.

7. **chown and USER switch**:
   ```
   RUN chown -R dev:dev /home/dev

   USER dev
   ENV HOME=/home/dev
   ```
   Leave the file ending at `USER dev` -- Plan 02 will append user-level installs.

**POSIX compliance (CONV-03):** All RUN commands must use `>/dev/null 2>&1` not `&>`. Use `. file` not `source file`. Use `[ ]` not `[[ ]]`.

**IMPORTANT:** Do NOT add any USER dev RUN commands yet (FVM, sdkmanager, Rust, CLAUDE.md append). Those are Plan 02.
