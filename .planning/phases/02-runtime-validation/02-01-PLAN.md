<task type="auto">
  <name>Task 1: Create runtime validation script</name>
  <files>scripts/validate-flutter-runtime.sh</files>
  <action>
Create `scripts/validate-flutter-runtime.sh` -- a bash script designed to run inside the Flutter devcontainer (`docker exec -it <container> bash /path/to/validate-flutter-runtime.sh`). The script must use `set -euo pipefail` and validate all Phase 2 runtime requirements in this order:

**Section 1: Inherited Tools Check (TOOL-02, TOOL-03)**
- Source NVM: `export NVM_DIR=/usr/local/nvm && . "$NVM_DIR/nvm.sh"`
- Verify: `nvm --version`, `node --version`, `npm --version` (all must print versions)
- Source UV PATH: `export PATH="$HOME/.local/bin:$PATH"`
- Verify: `uv --version` (must print version)
- Source Rust: `. "$HOME/.cargo/env"`
- Verify: `rustc --version`, `cargo --version` (quick recheck from Phase 1)
- Print PASS/FAIL for each tool

**Section 2: VNC Display Stack**
- Export `DISPLAY=:99`
- Start `Xvfb :99 -screen 0 1280x1024x24 &` and capture PID
- Poll with `xdpyinfo -display :99` in a loop (max 30 attempts, 1s sleep) -- critical for stability
- Start `x11vnc -display :99 -forever -nopw -rfbport 5900 -quiet &` and capture PID
- Print VNC ready message with port info

**Section 3: Android Emulator Boot (IDE-02 prerequisite)**
- Run `adb start-server`
- Start emulator: `emulator -avd flutter_pixel7 -gpu swiftshader_indirect -no-audio -no-boot-anim -no-snapshot -memory 2048 &` (do NOT use `-no-window` -- the window must be visible via VNC)
- Run `adb wait-for-device`
- Poll boot completion: loop `adb shell getprop sys.boot_completed 2>/dev/null | tr -d '\r'` until equals "1", with 5s sleep, 600s (10 min) timeout
- If timeout reached, print ERROR and `exit 1`
- Run `adb devices` and verify output contains "emulator-5554" with "device" status
- Print PASS

**Section 4: Android Studio Launch (IDE-02)**
- Start `/opt/android-studio/bin/studio.sh &` and capture PID
- Sleep 30s (Studio is heavy)
- Verify Studio process is still running with `kill -0 $STUDIO_PID`
- Run `adb devices` again to show emulator is visible to ADB (Studio uses same ADB)
- Print PASS or ERROR

**Section 5: Flutter Web Target (WEB-02)**
- `cd /tmp`
- `flutter create --platforms=web flutter_web_test`
- `cd flutter_web_test`
- `flutter build web` (this proves compilation works -- primary check)
- Clean up: `cd / && rm -rf /tmp/flutter_web_test`
- Print PASS

**Section 6: Cleanup**
- Kill Studio, emulator, x11vnc, Xvfb PIDs (use `kill $PID 2>/dev/null || true` for each)
- Print overall PASS/FAIL summary

**Script conventions:**
- Use POSIX-compatible constructs where possible (the script runs in bash but keep habits)
- Use `tr -d '\r'` on all adb shell output (adb returns \r\n)
- Print section headers with `echo "=== Section Name ==="` for easy log parsing
- At the end, print `ALL_CHECKS_PASSED` if everything succeeded (consistent with Phase 1 validation pattern)
- Make the script executable: `chmod +x`

**Important flags per research:**
- Do NOT use `-no-window` on emulator (need visible window for VNC verification)
- Do NOT use `-no-accel` unless `-gpu swiftshader_indirect` alone fails (try without first)
- The emulator boot with SwiftShader takes 2-5 minutes; 10-minute timeout is appropriate
