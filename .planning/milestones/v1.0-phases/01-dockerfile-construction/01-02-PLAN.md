  <files>trixie-vnc-flutter-rust-nvm-uv-claude/Dockerfile</files>
  <action>
Append the following sections to the existing Dockerfile after the `USER dev` / `ENV HOME=/home/dev` line created by Plan 01. Follow the order specified in CONTEXT.md: Android SDK components first, then FVM/Flutter, then Rust last.

**1. Android SDK components via sdkmanager (SDK-02, SDK-03, SDK-04, EMUL-01):**
```dockerfile
# ── Android SDK Components ───────────────────────────────────────────────────
RUN yes | sdkmanager --licenses >/dev/null 2>&1 \
    && sdkmanager \
        "platform-tools" \
        "platforms;android-35" \
        "build-tools;35.0.0" \
        "emulator" \
        "system-images;android-35;google_apis;x86_64"
```
Single RUN to keep all SDK component installs in one layer. The `yes | sdkmanager --licenses` must come first (SDK-04).

**2. Pre-created AVD (EMUL-02, EMUL-03):**
```dockerfile
# ── Android Emulator AVD ─────────────────────────────────────────────────────
RUN echo "no" | avdmanager create avd \
        --force \
        --name "flutter_pixel7" \
        --package "system-images;android-35;google_apis;x86_64" \
        --tag "google_apis" \
        --abi "x86_64" \
        --device "pixel_7" \
    && printf 'hw.gpu.enabled=yes\nhw.gpu.mode=swiftshader_indirect\nhw.ramSize=2048\nhw.sdCard.size=4096M\n' \
        >> $HOME/.android/avd/flutter_pixel7.avd/config.ini
```
Per user decisions: Pixel 7 profile, 2048 MB RAM, 4096 MB storage, SwiftShader rendering, AVD name `flutter_pixel7`.

**3. FVM + Flutter SDK (FLUT-01):**
```dockerfile
# ── FVM + Flutter ─────────────────────────────────────────────────────────────
RUN curl -fsSL https://fvm.app/install.sh | bash

ENV PATH=$HOME/.fvm/bin:$HOME/fvm/default/bin:$PATH
```
Install FVM, then set PATH. The exact FVM binary path may be `$HOME/.fvm/bin/` or `$HOME/.local/bin/`. After installing, if the build fails because `fvm` is not found, adjust the PATH to match where FVM actually installed. Check the install script output.

Then install Flutter stable:
```dockerfile
RUN fvm install stable \
    && fvm global stable
```

**4. Flutter doctor license acceptance + verification (FLUT-02, SDK-04):**
```dockerfile
# Accept Flutter-specific Android licenses
RUN yes | flutter doctor --android-licenses >/dev/null 2>&1 || true

# Configure Android Studio path for flutter doctor detection
RUN flutter config --android-studio-dir=/opt/android-studio 2>/dev/null || true
```
The `|| true` on license acceptance prevents build failure if licenses are already accepted. The `flutter config` ensures flutter doctor finds Android Studio (see Pitfall 3 in research).

**5. Rust toolchain (TOOL-01) -- copied from trixie-rust-nvm-uv-claude:**
```dockerfile
# ── Rust (via rustup, installed as user) ──────────────────────────────────────
RUN curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y \
    && . "$HOME/.cargo/env" \
    && rustup component add rustfmt clippy \
    && cargo install cargo-watch cargo-edit \
    && cargo install --locked cargo-nextest \
    && rm -rf "$HOME/.cargo/registry" "$HOME/.cargo/git"

RUN echo 'source "$HOME/.cargo/env"' >> /home/dev/.bashrc
```
This is an exact copy of the Rust variant's install block per user decision (duplicated logic).

**6. CLAUDE.md tools append (CONV-02):**
```dockerfile
RUN printf '\n### Flutter & Android\n- `flutter`, `dart` via FVM (`fvm`)\n- Android SDK: cmdline-tools, platform-tools, build-tools 35.0.0, API 35\n- Android Emulator with SwiftShader (AVD: flutter_pixel7, Pixel 7)\n- Android Studio Panda 1 at /opt/android-studio\n- `chromium` (CHROME_EXECUTABLE set for `flutter run -d chrome`)\n\n### Rust\n- `rustc`, `cargo`, `rustup`, `rustfmt`, `clippy`\n- `cargo-watch`, `cargo-edit`, `cargo-nextest`\n' >> $HOME/.claude/CLAUDE.md
```

**7. Build verification (FLUT-02) -- last RUN command:**
```dockerfile
# ── Build Verification ────────────────────────────────────────────────────────
RUN flutter doctor -v
```
This is the final build gate. If `flutter doctor` reports critical errors (red [!] marks for items that should be green), the build should fail. Do NOT add `|| true` here -- we want the build to fail on critical errors.

IMPORTANT: If flutter doctor shows a warning about Android Studio or licenses that is NOT a critical error (yellow [!] vs red [X]), that is acceptable for Phase 1. Only red critical errors should block the build. If flutter doctor exits non-zero on warnings, wrap with `RUN flutter doctor -v; exit 0` as a last resort, but add a comment explaining why.

**POSIX compliance (CONV-03):** All RUN commands must use `>/dev/null 2>&1` not `&>`. Use `. "$HOME/.cargo/env"` in the Rust block (dot, not source -- though both work since base symlinks sh->bash, dot is the POSIX convention).
